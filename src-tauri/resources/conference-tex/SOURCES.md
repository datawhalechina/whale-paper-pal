# Bundled conference LaTeX resources

The `.sty` and `.bst` files in this directory are unmodified third-party
conference author-kit resources. They are embedded for local compilation
convenience and retain their upstream copyright and licensing terms. They are
not covered by WhalePaper's MIT license.

Retrieved on 2026-08-05 from the following official sources:

| Conference | Version | Official source |
| --- | --- | --- |
| AAAI | 2027 | <https://aaai.org/wp-content/uploads/2026/05/AuthorKit27.zip> |
| NeurIPS | 2026 | <https://media.neurips.cc/Conferences/NeurIPS2026/Formatting_Instructions_For_NeurIPS_2026.zip> |
| ICML | 2026 | <https://media.icml.cc/Conferences/ICML2026/Styles/icml2026.zip> |
| ICLR | 2026, commit `a28d335b0d46a3c39b205704a65faf41c9748433` | <https://github.com/ICLR/Master-Template> |
| ACL | Current style, commit `d5adc823ff0f80f98c80405ca0ab66c68e684409` | <https://github.com/acl-org/acl-style-files> |
| CVPR | 2026, commit `291758547e923160eb4d37079b7b9f0dfce82355` | <https://github.com/cvpr-org/author-kit> |

Only conference-specific style and bibliography-style files are bundled.
General-purpose TeX packages remain supplied by the user's local TeX
distribution.
